---
title: Agents
description: The three agents Kiro Workbench installs, their models, and when to use each.
---

Kiro Workbench installs exactly three agents. Each is scoped to a role with a
fixed model — never `auto`, never a Haiku-class model — and its own tool
permissions.

## `dev` — the orchestrator

Model: **`claude-opus-4.8`**.

Plans, debugs, drives missions, and runs QA. This is the agent that reasons and
makes judgement calls; it delegates well-specified implementation work rather
than doing all of it inline.

- **Tools:** `read`, `write`, `shell`, `web`, `subagent`, `todo_list`, `goal`,
  `@mcp`.
- **Gates:** every gate in the system is wired to `dev` — mission, QA, git
  protection, and reuse-before-create all fire from this agent's tool calls.

Use it for: "implement X", "why is this failing", "set this as the mission",
"do QA", "review this design".

## `coder` — implementation sub-agent

Model: **`claude-sonnet-5`**.

The sub-agent `dev` delegates to for well-specified builds. Builds exactly the
spec it's handed — no scope expansion, no architectural decisions of its own —
and stops to report back rather than guessing when it hits a genuine ambiguity
or fork.

Use it for: implementation work delegated by `dev`, not invoked directly for
open-ended tasks.

## `scout` — read-only lookups

Model: **`claude-sonnet-5`**.

Cheap file and symbol search — "where is X defined", "does this repo use Y".
`write` and `shell` are denied, so it can gather but never change anything.

Use it for: fast lookups you'd otherwise burn `dev`'s context on.

## Model-routing rule

Opus orchestrates, Sonnet builds. Never Haiku-class, never `auto`, for any
agent in this set — silently falling back to a cheaper model is a known cause
of quality misses that are hard to notice after the fact. This is enforced,
not just documented:

```sh
kiroctl doctor --governance
```

## Switching agents

```
/agent dev
/agent coder
/agent scout
```

You'll usually stay on `dev` — it delegates to `coder` and `scout` itself
rather than requiring you to switch by hand.
